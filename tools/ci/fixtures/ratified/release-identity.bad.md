# Release runbook (specimen)

**The release identity.** notyas releases are signed with the OpenPGP RSA-3072 key
`intnsity`, created 2026-08-15:

```
A1E9 53B2 5C6A 623B 77A1 D522 3AC4 BBCF E51A B37D
```

The rsa3072 project key was retired on 2026-08-19 and its secret material destroyed. A
document that still names it sends a verifier to a key that cannot check the release, and
sending someone to the wrong key is worse than naming none at all.
